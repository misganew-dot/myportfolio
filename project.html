⛰️ Ras Dejen Visitor Registration & Information Portal

An interactive, responsive, and dynamic web platform dedicated to Ras Dejen national tourism. It features a robust, secure tourist registration system with customized Amharic and English real-time form validation to prevent spamming, keyboard mashing, and invalid contact data input.

  • Dual-Language Validation: Strictly validates full names using regex supporting both Ethiopic (አማርኛ) and Latin alphabets dynamically.
  • Smart Spam Protection: Restricts repetitive keyboard spams and implements a strict email pattern that blocks placeholder/fake email chains.
  • Adaptive Content Rendering: Successfully processes valid user data to instantly hide the form, shift layouts, and unlock the interactive historical content area seamlessly.
HTML5 CSS3 Custom Layout JavaScript (ES6+) DOM Manipulation
