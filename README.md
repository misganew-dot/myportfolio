# 🌐 My Personal Portfolio Website

ይህ የእኔን የሙያ ጉዞ፣ የኢንፎርሜሽን ቴክኖሎጂ (IT) እውቀት፣ የዌብ ልማት (Frontend Web Development) ክህሎቶች እና የሰራኋቸውን ፕሮጀክቶች በአንድ ላይ አጠቃልሎ የያዘ የግል ፖርትፎሊዮ ድረ-ገጽ ነው።

## ✨ ዋና ዋና ክፍሎች (Website Sections)

* **Home:** ስለ እኔ አጭር መግለጫ እና ወደ ተለያዩ ክፍሎች በቀላሉ መሄጃ መንገዶችን የያዘ ዋና መግቢያ ገጽ።
* **MyHeritage:** ባህላዊ እሴቶችን እና የታሪክ ይዘቶችን የምናጋራበት ልዩ ክፍል።
* **Projects:** እስካሁን የሰራኋቸውን የዌብ እና የሲስተም ፕሮጀክቶች (ለምሳሌ የዩኒቨርሲቲ ፖርታል) የምናሳይበት ማሳያ።
* **About Me:** ስለ ትምህርት ዝግጅቴ፣ በቴክኖሎጂ ዘርፍ ስላለኝ ጥልቅ ፍላጎት እና ስለ ዋና ዋና ክህሎቶቼ በዝርዝር የሚያስረዳ ገጽ።
* **Contact:** ሰዎች፣ ቀጣሪዎች ወይም ሌሎች ፕሮግራመሮች እኔን በቀላሉ ማግኘት የሚችሉበት የደብዳቤ ፎርም እና አድራሻዎች።

---

## 🛠️ የተጠቀሙባቸው ቴክኖሎጂዎች (Tech Stack)

* **Frontend:** HTML5 (Semantic Structure), JavaScript
* **Styling:** CSS3 (Custom Responsive Layout & Design)
* **Hosting:** GitHub Pages (ድረ-ገጹ በኢንተርኔት ላይ በቀጥታ እንዲሰራ የተደረገበት)

---

## 🚀 ዋና ዋና ባህሪያት (Features)

* **Responsive Design:** በኮምፒውተርም ሆነ በማንኛውም የሞባይል ስልክ ስክሪን ሲከፈት ራሱን አስተካክሎ በሚያምር ሁኔታ የሚታይ።
* **Professional UI:** ንጹህ፣ ቀላል እና ለተመልካች ሳቢ የሆነ የቀለም እና የፊደላት አጠቃቀም (Typography)።
* **Clean Code:** ኮዱ ለንባብ እና ለቀጣይ ማሻሻያዎች እንዲመች ተደርጎ በስርዓት የተዋቀረ።
